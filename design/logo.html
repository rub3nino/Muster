The mark

An M that ends in a check

To muster is to call people together and count who is there. The mark draws the first letter and, where the last stroke of the M should fall, puts the tick you write next to a name at roll call: here, present, place secured.

It is drawn with the same rounded 2.4 stroke as the interface icons, so it sits in the sidebar like it belongs there, and it stays readable down to a 16 px browser tab.
